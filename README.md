## Цель работы

Организовать обмен данными между процессами несколькими IPC-механизмами и сравнить их: FIFO, Unix domain sockets, `multiprocessing.shared_memory` и `Pipe`.

## Что реализовано

- клиент–сервер калькулятор на именованных каналах FIFO;
- отдельный FIFO для ответа каждому клиенту;
- тот же сервис на `socket.AF_UNIX`;
- одновременная обработка нескольких клиентов отдельными процессами;
- передача массива из **10 000 000** чисел через SharedMemory и Pipe;
- корректная очистка FIFO, socket-файла и shared memory;
- безопасный вычислитель арифметических выражений без `eval()`.

## Запуск

### FIFO

```bash
# терминал 1
python3 fifo_server.py

# терминал 2
python3 fifo_client.py "(10 + 2) * 3"
```

### Unix socket

```bash
# терминал 1
python3 unix_server.py

# терминал 2
python3 unix_client.py "7 * 8 + 1"
```

### Benchmark

```bash
python3 benchmark_ipc.py
```

## Результат измерения

Для массива из `10^7` чисел в контрольном запуске:

```text
SharedMemory: 0.021796 s
Pipe:         0.110820 s
Pipe / SharedMemory: 5.08x
```

## Ключевой вывод

Shared memory быстрее для больших объёмов данных, потому что процессы работают с общей областью памяти и не передают весь массив через канал. Но разделяемая память требует особенно аккуратной синхронизации и очистки ресурсов. FIFO и сокеты удобнее для обмена сообщениями и построения клиент–серверного взаимодействия.
